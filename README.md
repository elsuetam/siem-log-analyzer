# SIEM / Log Analyzer

Ferramenta de análise de logs e detecção de ameaças (Blue Team), desenvolvida em Python com foco em
arquitetura limpa, modularidade e boas práticas de engenharia de software.

## Status do projeto

🚧 Em desenvolvimento ativo — construído incrementalmente, etapa por etapa.

## Objetivo

Ler logs de servidores/aplicações, interpretar diferentes formatos, detectar atividades suspeitas
(brute force, scanners, SQL Injection, Directory Traversal, IPs maliciosos, entre outros), calcular
score de risco, correlacionar eventos, gerar incidentes e produzir relatórios e dashboards.
